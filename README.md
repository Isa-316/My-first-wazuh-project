# My-first-wazuh-project
I have complete all WAZUH configuration and implementation and simulate some attacks in my VMs 
This project demonstrates the use of Wazuh for security monitoring, threat detection, log analysis, and incident investigation in a simulated environment.

Objectives:-
Detect brute-force authentication attempts
Monitor Windows security events
Detect malicious or suspicious files
Monitor user-account activity
Analyze security alerts generated by Wazuh
